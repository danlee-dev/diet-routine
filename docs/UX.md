# 화면 구조 다시 짜기

기능이 늘면서 오늘 화면에 카드가 열 개 넘게 쌓였다 (기상, 주문, 상황 칩, 상황 배너, 지금 카드, 순서, 합계, 체중, 물, 걸음, 지키는 것, 패널 중복). 매일 여러 번 여는 앱이므로 "지금 할 일 하나"가 1초 안에 보여야 한다.

## 1. 사용 시나리오 (하루)

| # | 언제 / 어디서 | 하고 싶은 것 | 지금 걸리는 것 |
|---|---|---|---|
| S1 | 기상 직후, 폰 | 일어남 표시, 체중 기록, 첫 끼 시간 확인 | 버튼이 세 군데에 흩어져 있다 |
| S2 | 끼니 때, 폰 알림에서 | 먹었어요 / 다르게 먹었어요 (사진·말) | "다르게 먹었어요" 입구가 없다 |
| S3 | 외출·약속 직전, 폰 | 상황 바꾸기, 챙길 것 확인 | 칩 줄 + 배너 + 규칙 시트로 3단계 |
| S4 | 운동 시간, 폰 | 홈트 시작 / 걷기·러닝 시작 | 운동 탭까지 가야 한다 |
| S5 | 저녁, 폰·데스크톱 | 남은 칼로리, 마감까지 남은 시간, 오늘 정리 | 숫자가 여러 카드에 나뉘어 있다 |
| S6 | 주말, 데스크톱 | 체중 추세, 지킨 날, 다음 주 조정 | 기록 탭과 운동 탭에 나뉘어 있다 |
| S7 | 주문일, 아무 기기 | 주문할 것 확인, 쿠팡 열기 | 괜찮음 (오늘 위쪽 알림) |
| S8 | 아무 때나 | 코치에게 말로 묻고 고치기 | (1단계에서 추가) 들어갈 자리가 필요 |

## 2. 레퍼런스에서 가져올 원칙

- Oura 2025 개편: 탭 5개를 3개(Today / Vitals / My Health)로. Today 는 신문 1면처럼 "시간대에 맞는 한 가지"와 타임라인
- WHOOP 2025 홈: 위에 핵심 숫자 3개, 기록·운동 시작은 액션 버튼 하나로
- MacroFactor 대시보드: 칼로리·단백질만 크게, 나머지는 더 보기
- Structured: 하루를 세로 타임라인 한 줄로, 오늘로 돌아오기
- Gentler Streak: 시각 요소 하나 + "오늘의 추천" 하나
- Bevel: 코치가 지금 보는 화면 맥락을 같이 받는다
- 데스크톱 내비게이션: 영역이 3~5개면 사이드바 대신 상단 탭, 이동·실행은 명령 팔레트(⌘K)

## 3. 정보 구조: 5개 탭 -> 3개 + 액션 하나

| 영역 | 담는 것 | 이전 |
|---|---|---|
| **오늘** | 지금 할 일 하나, 하루 타임라인(끼니·운동·마감), 빠른 기록 줄, 오늘의 추천 하나 | 오늘 + 운동 탭의 "오늘 운동" |
| **기록** | 체중 추세, 30일 달력, 운동·러닝 기록, 주간 리포트 | 기록 |
| **계획** | 상황별 규칙, 홈트 루틴, 장보기·주문, 내 식품, 지키는 것, 동기화·설정 | 운동, 장보기, 상황별 |
| **+ (액션)** | 먹었어요 / 다르게 먹었어요(사진·말) / 체중 / 물 / 걸음 / 홈트·걷기 시작 / 코치에게 말하기 | 화면 곳곳의 버튼 |

## 4. 오늘 화면 우선순위

1. **머리**: 날짜·N일째, 오늘 상황(누르면 바로 바꾸는 메뉴), 칼로리 진행선 한 줄
2. **지금 카드**: 시간대마다 바뀌는 할 일 하나
   - 기상 전: "일어났어요"
   - 끼니 시간: 다음 끼니 + 먹었어요 / 다르게 먹었어요
   - 운동 추천 시간: 홈트 시작
   - 저녁 이후: 마감까지 남은 시간
   - 다 끝난 뒤: 오늘 정리
3. **빠른 기록 줄**: 체중 · 물 · 걸음을 한 줄짜리 알약 세 개로 (큰 타일 세 개 대신). 체중·걸음은 누르면 휠·키패드, 물은 누르면 +1잔
4. **오늘의 추천 하나**: 한 줄 카드. 주문일이면 주문, 17시 이후 걸음이 모자라면 걷기, 물이 늦으면 물, 아니면 상황 규칙 한 줄
5. **타임라인**: 왼쪽에 시간, 오른쪽에 항목. 기상 -> 아침 -> 점심 -> 간식 -> 홈트 -> 운동 후 -> 저녁 -> 20:00 마감. 끝난 항목은 한 줄로 접히고, 지난 항목은 표시

빠지는 것: 상황 칩 줄과 배너(머리 메뉴로), 하루 합계 줄(머리 진행선으로), 지키는 것(계획으로), 데스크톱 패널의 중복 기록 타일

## 5. 기기별 배치

**폰**
- 하단: [오늘] [기록] (+) [계획]. 가운데 +는 기록 시트를 띄운다 (WHOOP 액션 버튼)
- 지금 카드가 첫 화면을 차지하고, 스크롤하면 타임라인

**데스크톱 (1100px 이상)**
- 왼쪽 사이드바를 없앤다. 위쪽 한 줄: 이름 | 오늘·기록·계획 | ⌘K 검색·실행 | 동기화 상태
- 오늘: 가로로 넓은 화면을 쓰는 **가로 하루 자**. 기상부터 20:00까지 한 줄 위에 끼니·운동이 놓이고 지금 위치가 표시된다. 아래는 2단 (왼쪽 지금 카드 + 타임라인 상세, 오른쪽 숫자·추천·코치)
- ⌘K: "체중 기록", "물 +1", "홈트 B 시작", "외출로 바꾸기", "장보기" 등 모든 동작을 키보드로

**태블릿**: 폰 구조에 2단 배치

## 6. 구현 상태 (2026-11-15)

- 웹에 적용: 오늘 / 기록 / 계획 + 기록하기(+), ⌘K(초성 검색), 데스크톱 가로 하루 자, 건너뛰기, 다르게 먹었어요(프리셋·직접 입력)
- 남은 칼로리 = 하루 목표 - 먹은 양. 남은 계획대로 먹으면 넘칠 때 "계획대로면 +N"
- 아이폰 앱은 같은 구조로 만든다 (packages/data 의 focusNow, timeline, recommendation 을 그대로 사용)

## 7. 첫 실행: 스플래시 · 환영 · 온보딩 (아이폰, 2026-11-15)

다른 사람이 처음 설치해도 자기 루틴, 식단, 쿠팡 장보기 목록을 받게 하는 흐름. 소유자 설치는 기존처럼 자동으로 넘어간다.

### 참고한 것과 피한 것

- Apple HIG 온보딩: 짧게, 필요한 것만, 스플래시는 "한눈에" 정도. WWDC25: 온보딩 제목은 왼쪽 정렬, 굵게
- Apple 피트니스 목표 설정: 큰 숫자 하나에 − / + (휠 대신). 운동 횟수에 그대로 사용
- MacroFactor: 질문을 장(챕터)으로 묶고, 계산 근거를 숫자로 보여 준다
- Screensdesign 2026 정리: "답 하나마다 눈에 보이는 변화가 있어야 한다"
- 피한 것 (Cal AI 계열 템플릿): 얇은 진행 막대 + 가운데 제목 + 일러스트, 97% 같은 가짜 진행률과 체크리스트, 동기부여 문구 순환, 오브를 배경 장식이나 "AI가 생각 중" 표시로 쓰기

### 방향

- **오브에 할 일을 준다**: 네이티브 스플래시의 오브가 한 번 숨 쉬고(커졌다 작아짐, 반복 없음) 그라디언트가 돌아가며 앱 이름 "다루"가 자간을 좁히며 나타난다. 그다음 같은 오브가 환영 화면 오른쪽 위로 날아가 낮게 뜬 해처럼 자리 잡는다. 이미 쓰던 사람은 오브가 커지며 사라지고 오늘 화면이 드러난다. 약 1.2초, 동작 줄이기 설정이면 움직임 없이 페이드만
- **환영 = 로그인 화면**: 왼쪽 정렬 큰 제목 "끼니와 운동, 장볼 것까지 정해 드립니다." + 한 줄 설명 + 시작하기 / 이미 계정이 있습니다. 로그인은 같은 자리에서 Google · 이메일 코드로 바뀐다. 로그인 후 첫 동기화를 기다려 계획이 있으면 오늘로, 없으면 질문으로
- **진행 표시는 장 네 개**: 나 · 목표 · 생활 · 식사·운동. 각 장 이름 아래 짧은 막대가 그 장 안에서 얼마나 왔는지 보여 준다. 고정된 채움, 깜빡임 없음
- **답이 바로 숫자로**: 기간을 고르면 하루 kcal · 주당 감량 · 끝 체중, 기상 시간을 고르면 끼니 시각, 예산을 바꾸면 그 답으로 짠 식단의 주간 비용이 바로 바뀐다. 아래쪽 한 줄 요약(하루 1,820kcal · 남성 · 30세 …)이 답할수록 쌓인다
- **계산 장부, 가짜 로딩 아님**: "계산하는 중입니다" 화면은 기초대사량 → 하루 소모(활동량 배수) → 줄일 양 → 하루 목표 → 단백질 → 끼니 · 운동 · 장보기를 한 줄씩 진짜 숫자로 보여 준다. 오프라인 계획은 이미 다 나와 있고, 로그인했으면 코치 다듬기 단계가 아래에 이어진다. 기다리지 않고 넘어갈 수 있다
- **선택은 반전으로 표시**: 고른 칸은 전경색으로 채우고 글자를 뒤집는다. 색 테두리, 반투명 틴트, 파스텔 아이콘 원 없음. 화면당 컨테이너 한 겹

### 질문 (13개)

| 장 | 질문 | 컨트롤 |
|---|---|---|
| 나 | 부를 이름(선택) · 성별 · 나이 · 키 · 평소 활동량 | 입력칸 · 큰 선택 칸 · 휠 · 휠 · 선택 칸 |
| 목표 | 지금 체중과 목표 · 기간(4/8/12주) | 두 칸 전환 + 휠 · 세 칸 |
| 생활 | 보통 일어나는 시간 · 밖에서 먹는 끼니 | 시·분 휠 · 선택 칸 |
| 식사·운동 | 직접 하는 조리 · 못 먹는 것(선택) · 운동 장소와 주 몇 회 · 주간 장보기 예산(선택) | 선택 칸 · 칩 + 입력 · 선택 칸 + −/+ · 키패드 + 칩 |

활동량은 목표보다 먼저 묻는다. 기간 화면의 kcal가 기본값이 아닌 실제 활동량으로 계산되게 하기 위해서다. 한 개만 고르는 질문은 누르면 0.26초 뒤 다음으로 넘어간다.

### 구조

- 게이트: 루트 레이아웃의 `Stack.Protected` 두 개. 프로필이 없으면 welcome · onboarding, 있으면 (tabs). 온보딩 저장이나 로그인 후 동기화로 프로필이 생기면 화면 코드가 직접 이동하지 않아도 오늘로 바뀐다
- 설정 "내 정보 다시 입력": 같은 질문을 저장된 답으로 채워 다시 열고, `replacePlan` + 프로필 목표(kcal, 단백질, 기간)를 함께 바꾼다. 시작일과 기록은 그대로, 기간은 오늘부터 고른 주수만큼. 되돌리기 한 번으로 둘 다 되돌린다
