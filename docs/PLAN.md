# 감량 루틴 — 아이폰 앱 + 웹 계획

1인용. 목표: 76kg -> 70kg (시작 2026-11-15, 30일). 매일 열어 쓰는 도구가 되는 것이 기준이다.
아이폰은 기록·알림·러닝·건강 앱 연동의 중심, 데스크톱 웹은 같은 데이터를 크게 보고 계획을 고치는 곳.

---

## 1. 구조

homecheck 와 같은 pnpm 모노레포.

```
apps/mobile      Expo (dev build, TestFlight). iOS 네이티브 기능 전부
apps/web         Next.js 16 (Vercel, diet-routine.vercel.app 를 이어받음). UI + 서버 API
apps/web-legacy  지금 배포된 단일 HTML. web 이 대체하면 삭제
packages/core    순수 TS. 식단 데이터, 끼니 시간 계산, 칼로리 재분배, 체중 추세, 러닝 계산, 알림 계획
supabase/        migrations (raw SQL, RLS)
```

규칙
- 칼로리·시간·거리 계산은 `packages/core` 에서만 한다. 앱과 웹이 같은 함수를 쓴다 (vitest 로 검증)
- 웹-앱 패리티: 기록 화면과 계산 결과는 양쪽이 같아야 한다. 레이아웃은 기기마다 다르게 설계한다
- 키는 루트 `.env.local` 과 Vercel env 에만. 앱 번들에 Claude 키를 넣지 않는다 (AI 호출은 `apps/web/app/api/*` 경유)

### 동기화
- Supabase (Postgres + Auth + Realtime). 1인용이어도 RLS 는 `user_id = auth.uid()` 로 건다
- 로그인: 아이폰은 Sign in with Apple, 웹은 Apple 또는 이메일 링크
- 앱은 오프라인 우선: 기기에 먼저 쓰고 큐로 올린다. 레코드마다 `updated_at`, 충돌은 최근 값 우선
- 웹은 Realtime 구독: 폰에서 먹음 표시하면 데스크톱 화면이 바로 바뀐다
- 지금 브라우저에 쌓인 기록은 기존 "백업 코드"를 그대로 읽어 들이는 가져오기로 옮긴다

### 데이터 (초안)
| 테이블 | 내용 |
|---|---|
| profile | 키, 시작 체중, 목표, 시작일, 기본 기상 시간, 알림 설정 |
| day_log | 날짜, 상황, 외식 끼니, 기상 시간, 물, 걸음, 메모 |
| meal_log | 날짜, 끼니, 상태(계획대로/다르게/건너뜀/추가), 실제 음식·kcal·단백질, 출처(계획/프리셋/AI 글/AI 사진) |
| weight | 날짜, kg, 출처(직접/건강 앱) |
| workout | 날짜, 홈트 A/B, 완료 라운드, 시간, kcal |
| run | 시작·끝, 거리 m, 이동 시간, 페이스, kcal, 상승 고도, 케이던스, km 구간, 경로(인코딩 폴리라인) |
| pantry | 식품 재고(헬로틴, 큐브, 계란 등), 끼니마다 차감 |
| shop / orders | 장보기 체크, 주문 기록 |

### AI (Claude)
- `POST /api/ai/meal`: 사진 또는 글("점심에 김치찌개랑 공기밥") -> 음식 목록과 kcal·단백질·탄수·지방·확신도 (structured output)
- `POST /api/ai/label`: 영양성분표 사진 -> 내 식품 목록에 추가
- 모델 기본값 `claude-opus-5-5`. 사진 1장에 대략 수 센트 수준. 더 싸게 하려면 `claude-haiku-5-5` 로 바꿀 수 있다 (결정은 사용자)
- Supabase JWT 확인 후에만 호출. 하루 호출 수 상한을 둔다

## 2. 기능

### 2.0 AI 코치 채팅 (앱·웹 공통)
말로 기록하고 말로 계획을 바꾼다. 화면 어디서든 열리는 채팅 시트.

- "점심에 순대국이랑 밥 반 공기 먹었어" -> 음식 분석 -> 점심 기록 -> 남은 끼니 재분배 -> 필요하면 걸음·홈트 조정까지 한 번에 제안
- "닭가슴살 질려, 이번 주 간식 다른 걸로" -> 단백질을 지키는 대체안 + 장보기 목록 변경
- "내일 저녁 회식이야" -> 내일 계획 미리 조정 + 당일 아침 알림 예약
- "오늘 무릎이 좀 아파" -> 하체 홈트를 상체·걷기로 바꾸고 강도를 낮춤
- "이번 주 어땠어?" -> 체중 추세·지킨 날·러닝을 근거로 답
- 사진도 채팅에 바로 올린다

동작 원칙
- Claude 도구 사용(tool use). 도구는 core 함수를 그대로 감싼다: `get_today`, `log_meal`, `estimate_food`, `rebalance_day`, `swap_item`, `plan_event`, `adjust_workout`, `set_scenario`, `get_trends`
- **데이터를 바꾸는 도구는 바로 실행하지 않는다.** "이렇게 바꿀까요?" 변경 카드(전/후 kcal, 바뀌는 끼니·운동)를 보여주고 [적용]을 눌러야 저장
- 답변 속 숫자는 도구가 돌려준 값에서만 나온다 (계산은 core 가 하고 AI 는 설명만)
- 대화 기록은 Supabase 에 저장해 폰과 데스크톱에서 이어진다
- 모델 기본값 `claude-opus-5-5`
- 식단·내 식품에 답이 없으면 웹 검색(Claude 서버 도구 `web_search`)으로 제품 정보·먹는 법을 찾아 출처와 함께 답한다
- 끼니·음식 단위만이 아니라 항목의 양, 설명, 먹는 법 메모까지 고친다

예시: "프로틴 1스쿱 어떻게 먹어? 우유에 타도 돼?"
1. 단계 표시: "식단에서 프로틴 찾는 중" -> "제품 정보 확인 중 (웹 검색)" -> "바꿀 안 만드는 중"
2. 답: 운동 후 끼니가 이미 저지방 우유 200ml 를 포함해 210kcal·단백질 30g 으로 잡혀 있으니 우유에 타서 먹으면 된다. 물에 타면 약 120kcal 로 줄어든다. 출처 링크 표시
3. 변경 카드: 운동 후 · 프로틴 "1스쿱" -> "1스쿱(약 30g)을 저지방 우유 200ml 에 타서 흔들기 · 물이면 300ml" [적용] [보기]
4. 적용하면 `plans` 에 새 버전으로 저장, 오늘 화면의 운동 후 줄에 "코치가 바꿈" 태그, 누르면 이 대화로

식단 구조 자체를 대화로 바꾼다
- 끼니 안의 음식만이 아니라 끼니 단위로: "간식 빼줘", "아침이랑 점심 합쳐", "운동 후 프로틴을 저녁 전으로", "평일엔 아침 안 먹을래"
- 식단표는 코드가 아니라 데이터(`plans` 테이블, `effective_from` 부터 적용). 오늘만 바꾸는 건 `plan_adjustments`
- 바꿀 때는 core 가 칼로리·단백질을 다시 계산하고, 단백질이 하한 아래로 내려가면 다른 끼니로 옮기는 안을 같이 낸다
- 도구: `get_plan`, `propose_plan_change`(전/후 계산만, 저장 안 함), `apply_change`(카드 승인 후)

건너뛴 끼니
- 끼니마다 "건너뛰기". 0kcal 로 기록하고 줄어든 단백질과 대처법을 보여준다 (예: 간식을 건너뛰면 닭가슴살을 저녁에 더해 3팩 유지)
- 같은 끼니를 자주 건너뛰면 코치가 "평일 아침을 빼고 점심을 늘릴까요?" 처럼 식단표 변경을 먼저 제안한다

답변은 글보다 화면으로
- 코치 답변은 텍스트 + 블록. 블록은 앱 컴포넌트로 그린다
  - **변경 카드**: 바뀐 끼니·음식·운동을 전/후로 나란히, 칼로리·단백질 증감, [적용] [되돌리기] [보기]
  - **보기 링크**: 누르면 오늘 화면의 해당 끼니로 이동해 잠깐 강조 (예: 저녁 줄에 "닭가슴살 +1" 표시)
  - **끼니 카드, 하루 타임라인 미리보기, 체중 미니 차트, 홈트 카드, 장보기 변경 카드**
- 적용된 변경은 오늘 화면에도 표시가 남는다 (끼니 옆 "코치가 바꿈" 태그, 누르면 그 대화로)
- 모든 변경은 카드에서 되돌릴 수 있고 `plan_adjustments` / `plans` 에 이유와 함께 남는다

스트리밍 (기다리는 동안 지루하지 않게)
- 서버(`/api/ai/chat`)는 SSE 로 이벤트를 흘린다: `status`, `text`, `card`, `done`
- **지금 하는 일을 단계로 보여준다**: "점심 기록 확인 중" -> "순대국 칼로리 계산 중" -> "남은 끼니 다시 맞추는 중" -> "걸음 목표 확인 중". 도구가 시작·끝날 때마다 한 줄씩 추가되고, 끝난 줄에는 체크가 붙는다
- 도구 사이의 진행 메모는 Claude 의 진행 요약(`display: "updates"`)을 받아 같은 단계 줄로 보여준다
- 답 글자는 토큰 단위로 바로 흘러나오고, 계산 결과는 도착하는 즉시 카드(전/후 kcal, 바뀐 끼니)로 끼워 넣는다
- 깜빡이는 점·점멸 표시는 쓰지 않는다. 새 단계 줄이 살짝 올라오며 나타나는 정도의 움직임만
- 앱은 `expo/fetch` 스트리밍, 웹은 `fetch` + ReadableStream. 중간에 끊기면 마지막 이벤트부터 이어받는다

### 2.1 식단 엔진 (core)
- **다르게 먹었을 때**: 끼니마다 "다르게 먹었어요". 세 가지 입력
  - 자주 먹는 외식 프리셋 (치킨 반 마리, 짜장면, 삼겹살 1인분+소주 반 병, 떡볶이, 마라탕, 편의점 도시락 ...) + 양(적게/보통/많이)
  - 글로 쓰기 -> AI
  - 사진 찍기 -> AI
- **오늘 재분배**: 남은 끼니에서 밥·고구마부터 줄이고 닭가슴살·계란은 지킨다. 단백질 110g 아래로 내려가지 않는다
- **넘친 만큼 나눠 갚기**: 오늘 안에 못 맞추면 다음 3일에 하루 최대 200kcal 씩. 하루 1,200kcal 아래로는 안 내린다. 아주 크게 넘치면(회식) 깎는 대신 다음 날 걸음 목표를 올린다. "갚기" 타임라인으로 보여준다
- **미리 알리는 약속**: 아침에 "저녁 회식"을 넣으면 점심·간식을 미리 가볍게, 가기 전 단백질, 술 고르는 법(하이볼·소주 vs 맥주)까지 바꿔준다
- **체중 추세**: 매일 체중은 작게, 지수평활 추세값을 크게. 외식 다음 날 오르면 "소금 때문에 생긴 물 무게"로 설명
- **적응형 목표**: 체중·섭취 기록이 10일 이상 쌓이면 실제 유지 칼로리를 추정해 주 0.7~1.0kg 감량 속도에 맞게 주간 목표를 조정한다
- **도착 예정일**: 지금 추세로 70kg 에 닿는 날짜

### 2.1.1 계획 편집 (손으로, 코치로)

- 식단과 운동 계획은 버전으로 저장한다: `plans` 한 행 = 그날부터 적용되는 계획 (`slots.meals` 끼니별 변경, `workout` 주간 일정·루틴 구성). 같은 날 여러 번 고치면 그날 행 하나를 갱신하고, 모든 수정은 되돌리기를 준다.
- 하루만 바뀌는 것은 `plan_adjustments` (재조정 감량, 단백질 추가, 이월, 오늘만 운동 바꾸기 `kind: 'workout'`).
- 웹·앱·코치가 같은 함수로 쓴다 (`packages/data/src/plan.ts`): `setMealOverride`, `setWeekDay`, `setRoutineItems`, `setTodaySession`, `addAdjustments`, `savePlan`, `resetWorkout`. 화면은 `todayView` 의 `meals`, `week`, `routines`, `session`, `target` 만 읽는다.
- 계획 탭 맨 앞에 "식단" 표: 끼니마다 시간, 항목과 양, kcal, 단백질, 하루 합계와 목표. 끼니를 누르면 항목 바꾸기·빼기·시간 바꾸기. 바뀐 끼니에는 "내가 바꿈" 또는 "코치가 바꿈" 과 이유를 작게 보여준다.
- 홈트: 요일별 일정 (A, B, 걷기, 가볍게, 휴식) 을 눌러서 바꾸고, 루틴 운동 목록과 횟수를 고친다. 오늘만 바꾸기와 주간 계획 바꾸기를 구분한다.
- 코치 도구는 위 함수와 같은 변경을 카드로 제안하고, 사용자가 적용을 눌러야 쓴다.

### 2.2 걷기·러닝 (Nike Run Club 수준)
- 시작 전 GPS 잡기 (정확도 숫자로 표시, 움직이는 표시 없음)
- 기록 중: 거리, 시간, 현재 페이스(최근 30초), 평균 페이스, kcal, 케이던스, 상승 고도
- **정확한 거리**
  - 정확도 20m 넘는 점은 버리고, 순간 속도가 사람이 낼 수 없는 점도 버린다
  - 칼만 필터로 경로를 다듬고, 10초 넘게 멈추면 자동 일시정지
  - 고도는 기압계(GPS 고도보다 정확)를 쓴다
- 지도에 **실제 달린 선 그대로** 표시 (Apple 지도, 키 불필요). km 마다 구간 표시
- 1km 마다 음성 안내 ("1킬로미터, 6분 12초 페이스"), 음악 소리는 잠깐 줄인다
- 잠금화면·다이내믹 아일랜드 Live Activity: 거리·시간·페이스
- 끝나면: 요약, km 구간 페이스 차트, 오늘 식단에 미치는 영향(소모 kcal 의 절반만 오늘 여유로 반영, 설정 가능)
- 건강 앱에 운동 + 경로로 저장 -> 피트니스 앱·활동 링에 반영
- **내 지도 (땅 먹기 대신 실제 길)**
  - 달린 모든 길이 정확한 선으로 쌓이는 개인 지도
  - 한 바퀴 돌아 닫힌 고리는 "내 땅"으로 칠하고 면적(m²)을 계산한다
  - 달릴 때마다 "새로 달린 길 1.2km" 처럼 처음 가본 길을 따로 센다
- **공유 카드**: 경로 모양 + 거리·페이스·시간 + "N일째 · -2.1kg". 인스타 스토리용 투명 배경 경로 스티커
- 구현 메모 (`packages/core/src/run.ts`, `packages/data/src/run.ts`)
  - 거리는 필터를 거친 점 사이를 5m 단위로만 센다 (서 있을 때 흔들림이 거리로 쌓이지 않게). 멈춤·끝낼 때 마지막 몇 m 는 최신 위치까지 채운다
  - 0.5m/s 아래로 10초 넘게 있으면 자동 일시정지, 그 10초도 이동 시간에서 뺀다. 1m/s 를 넘거나 멈춘 곳에서 20m 넘게 움직이면 다시 기록한다. 걷기는 0.3/0.6m/s
  - 1분 넘게 위치가 끊기면 끊긴 구간의 속도로 터널(센다)과 앱 종료·정지(안 센다)를 가른다. 안 세는 끊김과 직접 일시정지는 경로를 새 구간으로 나눠서 지도에 직선이 그어지지 않는다
  - `runs.polyline` 은 구간마다 인코딩한 폴리라인을 공백으로 이어 붙인 값이다 (`runSegments`). 공백 없는 예전 값은 한 구간으로 읽힌다
  - kcal 는 km 구간마다 속도별 MET(Compendium)로 계산한 활동 칼로리((MET-1) x 체중 x 시간). 휴식 대사는 이미 유지 칼로리에 들어 있어서 뺀다
  - 오늘 목표 kcal 에 run kcal x 0.5 를 더한다. `profiles.preferences.run_credit_ratio` 로 바꿀 수 있다
  - 걸음을 직접 입력하는 날에는 추정 걸음을 더하고, 건강 앱 걸음인 날은 건드리지 않는다
  - 고도는 아직 GPS 고도(약 10초 평활, 4m 미만 오르내림 무시). 기압계, 케이던스, Live Activity, 건강 앱 저장은 다음 단계
  - 앱이 기록 중에 종료되면 다시 열 때 이어서 기록한다. 마지막 위치가 20분보다 오래됐으면 일시정지 상태로 복원하고 GPS 는 켜지 않는다

### 2.3 홈트
- 지금 플레이어를 네이티브로: 햅틱, 음성 카운트, 휴식 타이머 Live Activity, 화면 꺼짐 방지
- 건강 앱에 근력 운동으로 저장

### 2.4 건강 앱 (HealthKit)
- 읽기: 걸음(자동, 직접 입력 불필요), 활동 에너지, 수면(기상 시간 자동 감지), 체중(스마트 체중계 쓰면 자동), 애플워치 운동
- 쓰기: 체중, 러닝·걷기(경로 포함), 홈트, 섭취 kcal·단백질(선택)
- 백그라운드 전달: 수면이 끝나면 앱이 깨어나 오늘 끼니 시간과 알림을 다시 계산한다

### 2.5 푸시 알림 (기기에서 예약, 서버 불필요)
계획 함수는 core 에 두고 테스트한다. 하루 최대 6~7개, 밤 11시~기상 전은 조용히.

| 언제 | 내용 | 알림에서 바로 |
|---|---|---|
| 기상 감지 | "좋은 아침이에요. 체중 재고 기록해요" | 숫자 입력해서 바로 저장 |
| 끼니 시간 (안 먹었을 때만) | "점심 15:00 · 닭가슴살 큐브 + 현미밥 반 공기" | 먹었어요 / 다르게 먹었어요 |
| 저녁 마감 30분 전 | "저녁 마감까지 30분" | 먹었어요 |
| 홈트 추천 시간 (A/B 요일) | "홈트 B 하체 · 17:40 · 25분" | 시작 |
| 18:30 걸음 60% 미만 | "2,300보 남았어요. 지금 20분 걸으면 채워요" | 걷기 시작 |
| 물 속도가 늦을 때 2번 | "물 3잔째 마실 시간" | +1잔 |
| 21:30 기록 빈 끼니 | "오늘 기록 마무리" | 다 먹었어요 / 다르게 먹었어요 |
| 큰 초과 다음 날 아침 | "어제 +900kcal, 오늘부터 3일 동안 200kcal 씩 나눠요" | |
| 재고 3일분 남음 | "헬로틴 3일분 남았어요" | 쿠팡 열기 |
| 일요일 20:00 | 주간 리포트 (추세, 지킨 날, 다음 주 목표) | |

- 3일 연속 무시한 알림 종류는 자동으로 줄인다. "오늘은 알림 끄기" 하루 토글
- (선택) 위치: 평일 11시 이후 집을 나서면 "외출" 상황으로 바꾸고 밖에서 먹는 규칙 알림, 밤 9시 넘어 들어오면 "늦게 들어온 날"

### 2.6 아이폰 네이티브
- **위젯**: 작은 위젯(다음 끼니·시간), 중간 위젯(칼로리 구슬 + 물 +1 버튼, 앱 안 열고 기록), 잠금화면 원형(걸음·kcal)
- **Live Activity**: 러닝, 홈트 휴식, 저녁 마감 카운트다운
- **Siri·단축어·액션 버튼**: "체중 75.4 기록", "물 마셨어", "달리기 시작", "오늘 뭐 먹어?"
- **NFC 스티커 + 단축어**: 냉장고에 붙인 스티커에 폰을 대면 "닭가슴살 먹음"
- **뒷면 탭**: 두 번 톡 -> 물 +1
- **카메라**: 음식 사진 kcal 추정, 영양성분표 찍어서 새 식품 등록
- SF Symbols 아이콘, 햅틱, Apple 연속 곡률 모서리

### 2.7 웹 (데스크톱)
- 지금 디자인을 Next.js 로 옮긴다 (접히는 사이드바, 휠 피커 등 그대로)
- 데스크톱 전용: 큰 체중·섭취 차트, 러닝 기록 목록과 큰 지도(MapLibre + 무료 타일), 식단·프리셋·재고 편집
- 실시간 동기화
- 구현 메모
  - 상단 메뉴에 "운동" (휴대폰 하단 막대는 오늘 · 운동 · + · 기록 · 계획). 달리기 목록, 큰 경로 지도, km 구간 막대(높을수록 빠름, 점선은 평균), 내가 달린 길
  - 지도는 MapLibre GL + OpenFreeMap(positron / dark, 키 없음). 바탕 스타일의 색을 모두 같은 밝기의 회색(R=G=B)으로 바꾸고, 경로만 브랜드 그라데이션(orb1 → orb2)
  - MapLibre 워커 파일은 번들에 안 들어가서 `apps/web/scripts/copy-map-worker.mjs` 가 dev/build 전에 `public/maplibre/` 로 복사한다 (gitignore)
  - 기록: 넓은 화면에서 체중 차트를 전체 폭으로, 그 아래 하루 먹은 양 막대(목표까지 회색, 넘친 만큼 진하게, 점선은 그날 목표). 계산은 `intakeSeries` / `intakeSummary` (data)
  - 다르게 먹었어요 목록 편집: 설정 > 자주 먹는 음식, 또는 목록 아래 "목록 고치기"

### 2.8 그 밖에
- **재고 기반 주문**: 끼니를 먹을 때마다 재고가 줄고, 남은 일수로 주문 시점을 알려준다 (고정 주기 대신)
- **날씨**: 비 오는 걷기 날엔 홈트로 바꿔 제안 (Open-Meteo, 키 없음. 앱 번들에 새 네이티브 모듈 없이)
- **주간 회고 카드**: 가장 잘 지킨 날, 추세, 공유용 이미지
- 재고 구현 메모 (`packages/core/src/pantry.ts`, `packages/data/src/pantry.ts`)
  - 저장은 `profiles.preferences.pantry` 에 품목마다 `{ count, at }` 하나. "그 시각에 몇 개 있었다"만 저장하고, 그 뒤에 기록한 끼니가 쓴 만큼 빼서 지금 남은 양을 계산한다. 끼니 체크를 취소하면 남은 양도 돌아온다
  - 품목 단위는 상품 이름과 수량에서 읽는다: 개수(30개입, 30구), 무게·부피(1kg x 2개 = 2,000g, 1L x 2 = 2,000ml), 1인분 크기(햇반 130g x 36 = 36개). 크기가 없는 생성 목록은 온보딩 식품표의 1팩 분량을 쓴다
  - 식단 항목은 이름으로 장보기 품목에 맞춘다(같은 단어, 포함, 동의어: 달걀=대란, 귤=감귤, 프로틴=골드스탠다드, 샐러드=데일리믹스). 온보딩 식단은 식품표로 정확히 맞춘다. 편의점 음식과 외식(추정 끼니)은 재고에서 빼지 않는다
  - 하루 사용량은 오늘 계획의 "집에 있는 날" 기준. 남은 일수 3일 이하면 오늘 화면 추천 줄과 장보기 "곧 떨어지는 것"에 쿠팡 링크로 알린다. 리마인더용 순수 함수 `stockAlerts(pantryInput)` (core), `stockAlertsFor(env)` (data)
  - 장보기 체크 = 샀음: 남은 양 + 한 번 산 양. 체크를 풀면 사기 전 숫자로 돌아간다. 남은 양을 세는 품목은 날짜별 주문 알림에서 빠진다
- 날씨 구현 메모 (`packages/core/src/weather.ts`, `packages/data/src/weather.ts`)
  - 설정에서 켠 기기에서만 대략적인 위치(약 10km 단위로 반올림)를 쓰고, 아니면 설정에서 고른 도시(`profiles.preferences.weather_city`, 동기화)
  - 지금부터 21시 사이에 비 오는 시간이 2시간 이상이거나 한 시간에 3mm 이상이면 걷는 날 오늘 화면에 "홈트로 바꾸기"(그날만 `setTodaySession`). 오래 안 한 루틴(A/B)을 고른다. 20시 이후에는 묻지 않는다
- 프리셋: 사용자가 처음 고칠 때 기본 목록을 `foods`(source `preset`, 분류는 note) 로 복사한다. 고정 id 라서 두 기기가 동시에 복사해도 같은 행이 된다
